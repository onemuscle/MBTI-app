# TYPE ATLAS

16タイプ性格図鑑 × 関係性ナビゲーション Webアプリ（MVP）

「自分のタイプを知る」だけで終わらせず、「相手をどう理解し、どう伝え、どう関係を良くするか」まで支援することを目的としたアプリです。設計書 `TypeAtlas_WebApp_Design_Spec_JP_v2` に基づいて実装しています。

## 機能（MVPスコープ）

- **16タイプ図鑑** — 特徴・強み・盲点・会話のDO/DON'T・ストレスサイン・仕事/友達/恋愛プロファイル・成長アクション
- **人物登録** — ニックネーム・タイプ・関係・距離感・関係メモをローカル保存（登録/編集/削除）
- **3種の相性** — 仕事・友達・恋愛を別ウェイトで評価。6軸レーダー + 「うまくいく場面」「ズレやすい場面」「伝え方のコツ」「揉めた時のリカバリー」
- **接し方の保存** — 効きそうなコツをワンタップ保存、マイページで見返し
- **共有** — タイプと関係のみを含むURL共有（ニックネームは既定で非含有）
- **オリジナルキャラクター** — 幾何学フラットデザインのSVGを独自描画（既存サービスのキャラクターは不使用）

## 技術構成

- Next.js (App Router) + TypeScript + Tailwind CSS
- コンテンツは `src/data/types.json` でJSON管理（コード非埋め込み）
- 相性は `src/lib/compatibility.ts` のルールベースエンジン（6軸スコア × 関係別ウェイト）
- ユーザーデータは `localStorage` のみ（サーバー送信なし）。エクスポート/全削除に対応

## 開発

```bash
npm install
npm run dev   # http://localhost:3000
npm run build # 本番ビルド
```

## 注意事項

本アプリは自己理解と対話の補助ツールであり、科学的診断・能力評価ではありません。MBTI関連の商標・公式コンテンツは使用せず、ユーザーが自身のタイプを入力する方式を採用しています。
